# Deviza-lenyomatok

A deviza napi becslés-csomagjának lenyomata (SHA-256, méret, darabszámok),
hétköznap az EKB közlése után commitolva (`docs/fx-modell.md`, 5. fejezet).
Csak a fixálás (14:10 CET) után 6 órán belül készült becslés számít élőnek.

Az élő deviza-rekord az első itt lenyomatolt naptól számít.
