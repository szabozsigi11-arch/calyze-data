# Kripto-lenyomatok

A kripto napi becslés-csomagjának lenyomata (SHA-256, méret, darabszámok),
naponta 00:30 UTC után commitolva (`docs/kripto-modell.md`, 6. fejezet). A
commit időbélyege bizonyítja, hogy a becslés akkor már megvolt; maga a csomag
a privát tárban marad az adatlicenc rendezéséig, és utána bárki
újraszámolhatja a hash-t.

Az élő kripto-rekord az első itt lenyomatolt naptól számít.
