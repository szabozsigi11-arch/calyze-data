# Kötvény-lenyomatok

A kötvény napi becslés-csomagjának lenyomata (SHA-256, méret, darabszámok),
kötvénynapokon a pénzügyminisztérium közlése (18:00 ET) után commitolva
(`docs/kotveny.md`, 6. fejezet). Csak a 15:30-as (ET) felvétel után 6 órán
belül készült becslés számít élőnek.

Az élő kötvény-rekord az első itt lenyomatolt naptól számít.
