# manifests-arena/

A modell-aréna kihívóinak (`ar-linear`, `mlp-core`, `ensemble`) napi
lenyomatai, ugyanúgy, mint a `manifests/` mappában a fő modellé: a csomag
SHA-256 lenyomata és darabszámai, a csomag maga a privát tárban marad.

Külön mappában vannak, hogy a fő becslés lenyomatai (és az állapotoldal) ne
keveredjenek velük. Definíció: `docs/modell-arena.md`.
